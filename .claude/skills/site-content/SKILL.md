# Site content

Almost all copy lives in **`src/utils/constants.js`**. Components only render it.

## Content rules (owner-mandated — never break)
1. **No client names**, ever — not in case studies, blog posts, alt text or JSON-LD. Use sector descriptions only
   ("Financial Services", "Broadcast Media").
2. **No prices, budgets or currency** on the site. If cost comes up: "a clear proposal with scope, timeline and cost after a free requirement analysis".
3. Featured case studies (`featured: true`) are real in-house products: **Sinhala AI Proofreader** and **Graphic-Cast**. Don't inflate their facts.
   The other four (knowledge copilot, data migration, AWS platform, Azure + OCI) use owner-approved representative figures — keep them plausible.
4. Region wording: based in **Ragama, Sri Lanka**, serving **South Asia & beyond**.
5. Tone: confident, concrete, outcome-focused; British/Commonwealth readers but US spelling is already used — stay consistent (US spelling).
6. **No em dashes (—)** in any site copy, attributes or meta tags; rewrite with commas, colons, periods or parentheses.
   Check: `grep -rn "—" src index.html public` must return nothing.
7. Contact facts come from `COMPANY_INFO` — never hard-code phone/email in components.

## Changing company details
Update `COMPANY_INFO`/`SOCIAL_LINKS`, then also `index.html` (JSON-LD `email`, `telephone`, `address`, `sameAs`, noscript)
and `.env.example`. Domain changes: see the `seo` skill (sitemap, robots, OG image text).

## Adding a blog post
1. `src/content/blog/YYYY-MM-slug.md` with frontmatter: `title, date (YYYY-MM-DD), author, category, tags[], excerpt, slug`
   (`featured_image` optional — covers are generated by `BlogCover.jsx`). The first `# Title` line is stripped automatically.
2. Import it in `src/hooks/useBlogData.js` (`?raw`) and add to `rawPosts`.
3. Add `<url>` to `public/sitemap.xml` with `lastmod`.
4. New category? Add a tint in `BlogCover.jsx` `TINTS` (optional).
5. Build and open `/blog/<slug>` to check rendering. No tables/strikethrough (no remark-gfm).

Human-facing version of these instructions: `docs/CONTENT_GUIDE.md` — keep both in sync.

## After editing
`npm run build`; screenshot the changed section (`ui-verification`). Grep for leaked client names or prices:
`grep -rniE "hiru|\\$[0-9]|LKR|rs\\.? ?[0-9]" src index.html`.
